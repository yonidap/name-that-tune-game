# Audio snippets

Gameplay snippets live directly in this folder and must use the filenames referenced by `data/songs.js`.

Reveal snippets use a separate folder:

`public/audio/reveal/`

Each reveal file must use the exact same filename as its gameplay counterpart. For example:

- gameplay: `public/audio/poker-face.mp3`
- reveal: `public/audio/reveal/poker-face.mp3`

The reveal snippet is the full-song/original-audio version that plays automatically behind the answer reveal. It does not affect score or playback counts.

See `public/audio/reveal/README.md` for details.
